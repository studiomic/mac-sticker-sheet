
# About Mac PoTi

このページをつくった人は物覚えが悪いもので、たびたびMac Commandとググっていたときに、ある日突然スポンサー広告でMacBookに貼る
「ショートカットキー」ステッカーなるものが画像でずらりと並んでいました。

通販を見に行って何と便利そうな！と思ってすぐ真似することにした。

文章や説明はいらない、（なんだっけ）と思い出したいときに見る、知っているけど忘れがちなものを、シート化しました。

過去には、IllustratorやPhotoshopで作成されたであろう美しいショートカット表などをダウンロードさせてもらっていたけど・・・

「母さん、僕のあの帽子、いや壁紙になっているチートシート、どうしたんでせうね？」

<hr>
というわけで、失くさない場所（Web+Github）におく。

忘れるのはとにかくiTermで打ちたい Command ：touch　（なんだよ、タッチって）などなど

見るより、クリップボードコピーしたいので、自分の得意なHTMLでサクッとつくるのではなく、VitePressを使うことにしました。

ソースは右上のGithubアイコンをポチッと踏んでリポジトリにいけます。

### 内容

Markdownファイルを作成するときに、Mac Shortcut and Command Cheat Sheet
なんて書いてられなかったため、**なんとなくmac-poti.md**
とした。

それだけの命名で厳めしいプロジェクト名とかじゃないす。

（あら、便利そうね）とか（簡単そうね）と自己流にカスタムして使ってくださる方がいたら、幸いです。

<div style="margin-top: 2em;"></div>

<hr>

ショートカットの記載内容は、商品化されているものを、ほぼパクリました。<br>
デスクトップ派なので＋電源　などは使ったことないです。が、汎用性をとりました。<br>

また普段検索で見ているサイトやページを引用させていただいた Command部分は末尾にURLをリンクしました。
